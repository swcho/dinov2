# Sinkhorn-Knopp centering — 고등학생을 위한 설명

## 0. 결론부터

DINOv2 의 "teacher" 네트워크가 내놓는 **정답표(확률분포)** 를 만드는 방법을 바꾼 것이다. 원래는 "점수에서 평균을 빼고 softmax" 를 했는데, 이를 "표의 **가로 합과 세로 합을 번갈아 맞추는 것을 3번 반복**" 하는 Sinkhorn-Knopp(SK) 알고리즘으로 대체했다. 학생(student) 네트워크는 그대로 softmax 를 쓴다.

---

## 1. 점수를 확률로 바꾸는 softmax

네트워크가 어떤 이미지에 대해 $K$개의 "prototype"(서랍이라고 생각하자) 각각에 점수 $z_1, \dots, z_K$ 를 준다. 이것을 "이 이미지는 몇 번 서랍에 속할까" 라는 **확률분포** 로 바꾸는 표준 방법이 softmax 다.

$$p_k = \frac{e^{z_k/\tau}}{\sum_{j=1}^{K} e^{z_j/\tau}}$$

- 지수함수 $e^{x}$ 는 항상 양수이고 증가함수이므로, 점수가 크면 확률도 크다.
- 분모로 나누면 $\sum_k p_k = 1$ 이 되어 확률의 조건을 만족한다.
- $\tau$(온도)가 작으면 $z/\tau$ 의 차이가 커져서 1등 서랍에 확률이 몰린다(뾰족해진다). $\tau$ 가 크면 평평해진다.

> 고교 확률과 통계에서 "확률분포표" 의 각 값이 0 이상이고 합이 1 인 것과 같은 조건이다.

## 2. 왜 그냥 softmax 로는 안 되나 — "붕괴"

DINO 는 라벨(정답)이 없다. teacher 가 만든 분포 $p_t$ 를 student 가 흉내내도록 학습한다. 그런데 정답이 외부에서 주어지지 않으면 **가장 쉬운 편법** 이 있다: 모든 이미지에 대해 항상 "3번 서랍" 이라고 답하면 student 도 항상 3번 서랍이라 답해 손실이 0 이 된다. 정보는 하나도 없는데 문제는 풀렸다. 이것이 **collapse(붕괴)** 다.

DINO 의 원래 처방은 **centering**: 배치(한 번에 처리하는 $B$장의 이미지) 에서 각 서랍 점수의 평균 $c_k$ 를 구해 빼 준다.

$$z_k \leftarrow z_k - c_k$$

항상 3번 서랍 점수가 높다면 $c_3$ 도 커서 빼고 나면 이점이 사라진다. 다만 $c$ 는 과거 배치들의 평균을 조금씩 갱신한 값(지수이동평균) 이라 "지금 이 배치" 를 정확히 반영하지는 않고, 서랍 사용량이 정확히 같아진다는 보장도 없다.

## 3. 표(행렬)로 생각하기

이제 이미지 한 장이 아니라 배치 전체를 본다. 세로로 서랍 $K$개, 가로로 이미지 $B$장을 놓은 표를 만들고 각 칸에 $e^{z/\tau}$ 를 적는다. 예를 들어 서랍 2개, 이미지 3장이라면 (숫자는 임의):

|           | 이미지1 | 이미지2 | 이미지3 | **행 합** |
|-----------|--------|--------|--------|--------|
| 서랍 A    | 8      | 6      | 9      | 23     |
| 서랍 B    | 2      | 1      | 1      | 4      |
| **열 합** | 10     | 7      | 10     | 27     |

각 **열** 을 그 열의 합으로 나누면 이미지마다 확률분포가 된다 — 이것이 그냥 softmax 다. 그런데 세 이미지가 모두 서랍 A 에 몰려 있다(행 합 23 vs 4). 붕괴 조짐이다.

우리가 원하는 것은 두 조건을 **동시에** 만족하는 표다.

1. 각 열(이미지)의 합 = 1 (확률분포)
2. 각 행(서랍)의 합 = $B/K$ (모든 서랍이 똑같이 쓰임 — "공평 분배")

## 4. Sinkhorn-Knopp: 가로·세로 합 맞추기를 교대로

조건 1 을 맞추려 열을 나누면 행 합이 깨지고, 조건 2 를 맞추려 행을 나누면 열 합이 깨진다. 그래서 **교대로 반복** 한다. 표 전체 합을 1 로 만든 뒤 시작해 보자(위 표를 27 로 나눔).

**반복 1 — 행 정규화**: 각 행을 행 합으로 나누고 다시 $K=2$ 로 나눠 행 합을 $1/2$ 로 만든다.

|       | 이미지1 | 이미지2 | 이미지3 | 행 합 |
|-------|--------|--------|--------|------|
| A     | 0.174  | 0.130  | 0.196  | 0.5  |
| B     | 0.250  | 0.125  | 0.125  | 0.5  |
| 열 합 | 0.424  | 0.255  | 0.321  |      |

**반복 1 — 열 정규화**: 각 열을 열 합으로 나누고 $B=3$ 으로 나눠 열 합을 $1/3$ 으로 만든다.

|       | 이미지1 | 이미지2 | 이미지3 | 행 합  |
|-------|--------|--------|--------|-------|
| A     | 0.137  | 0.170  | 0.203  | 0.510 |
| B     | 0.197  | 0.163  | 0.130  | 0.490 |
| 열 합 | 0.333  | 0.333  | 0.333  |       |

행 합이 이미 0.5 에 가깝다(0.510 / 0.490). 이것을 2~3번 더 반복하면 행 합은 0.5, 열 합은 1/3 로 거의 동시에 맞는다. 마지막에 열 합이 1 이 되도록 $B$ 를 곱해 주면 각 이미지의 확률분포가 된다. 여기서 이미지1 은 A 보다 **B 서랍 확률이 더 높아졐다** — 원래 점수로는 A(8) > B(2) 였지만, "B 서랍도 공평하게 써야 한다" 는 제약이 상대적으로 B 점수가 높은 이미지1 에게 B 를 배정한 것이다. 이렇게 붕괴가 구조적으로 막힌다.

수학적으로 이 과정은 행에 곱하는 수 $u_k$ 와 열에 곱하는 수 $v_i$ 를 찾아

$$Q_{ki} = u_k \, e^{z_{ki}/\tau} \, v_i$$

꼴로 만드는 것이고, 1967년 Sinkhorn 과 Knopp 이 "양수 표라면 이런 $u, v$ 가 존재하고 교대 정규화가 그것으로 수렴한다" 는 것을 증명했다. 이 방법을 처음 자기지도학습에 쓴 것이 SwAV(2020) 이고, DINOv2 가 그것을 가져왔다.

## 5. 왜 딱 3번인가

각 반복은 "틀린 정도" 를 일정 비율 이하로 줄인다(등비수열처럼 줄어든다). 아래 실험(expy.py)에서 보듯 3번 뒤에는 행 합의 상대 오차가 $10^{-3}$ 근처로 떨어진다. teacher 의 정답표는 어차피 근사여도 학습에 충분하고, 128,000 개 서랍 $\times$ 수천 장 이미지 표를 여러 GPU 에 걸쳐 정규화하는 비용도 있으므로, SwAV 가 쓰던 값인 3회를 그대로 썼다.

## 6. student 는 왜 그대로 softmax 인가

- 붕괴를 막아야 하는 것은 **정답을 만드는 쪽(teacher)** 이다. student 는 그 정답에 맞추기만 하면 된다.
- SK 는 배치의 다른 이미지들의 값을 섞어 쓴다. student 출력에 SK 를 걸면 미분(역전파)이 배치의 모든 이미지에 얽혀 복잡해진다. teacher 는 학습하지 않는 쪽(`torch.no_grad()`)이라 문제가 없다.

## 7. 정리

| | 원래 DINO teacher | DINOv2 teacher (SK centering) |
|---|---|---|
| 붕괴 방지 | 점수에서 EMA 평균 $c$ 를 뺀 뒤 softmax | 표의 행·열 합을 교대로 3번 맞춤 |
| 서랍 사용량 | 대략 균등 | 이 배치 안에서 정확히 $B/K$ |
| 온도 $\tau$ | 사용 | 사용 ($e^{z/\tau}$ 로 시작) |
| student | softmax | softmax (변화 없음) |

$$\boxed{\;p_t = \mathrm{SK}_3\!\big(e^{z_t/\tau_t}\big),\qquad p_s = \mathrm{softmax}(z_s/\tau_s),\qquad \mathcal{L} = -\sum_k p_{t,k}\log p_{s,k}\;}$$
