# DINO 손실을 고등학교 수학으로 이해하기

## 0. 문제 설정을 말로 풀면

라벨(정답)이 없는 사진 수억 장이 있다. 그래도 신경망에게 "이 사진이 무엇인지" 압축한 벡터를 만들게 하고 싶다. DINO의 아이디어는 이것이다.

> **같은 사진을 서로 다르게 잘라(crop) 두 장을 만들었다면, 두 장에 대한 신경망의 "판단"은 같아야 한다.**

두 판단이 다르면 벌점(손실)을 주고, 그 벌점을 줄이는 방향으로 신경망을 고친다. 정답표는 없지만 "자기 자신과의 일관성"이 학습 신호가 된다.

## 1. 벡터와 "점수 벡터"

고교 기하에서 벡터는 $(x, y, z)$처럼 숫자 몇 개의 묶음이다. 신경망 안에서는 차원이 더 클 뿐이다. ViT라는 신경망은 사진 한 장을 넣으면 1024개 정도의 숫자로 된 벡터(**class token**)를 내놓는다. 이것을 사진의 "요약"이라 생각하자.

이 요약 벡터를 **DINO head**라는 작은 함수(여러 개의 1차함수와 비선형함수를 겹친 것, 즉 MLP)에 넣으면 길이 $K$(DINOv2에서는 65,536)인 **점수 벡터** $s = (s_1, s_2, \dots, s_K)$가 나온다. 각 $s_k$는 "이 사진이 $k$번째 가상 부류(prototype)에 얼마나 가까운가"를 뜻하는 실수다. 실제로 마지막 단계는 단위벡터 두 개의 내적, 즉 $\cos\theta$ 꼴이어서 $-1\sim 1$ 사이 값이다.

## 2. softmax: 점수를 확률로 바꾸기

확률과 통계에서 확률분포는 "모두 0 이상이고 합이 1"인 숫자 목록이다. 임의의 실수 점수 $s_k$를 확률로 바꾸는 표준 도구가 **softmax**다.

$$p^{(k)} = \frac{e^{s_k/\tau}}{\sum_{j=1}^{K} e^{s_j/\tau}}$$

* 지수함수 $e^x$는 항상 양수 → 모두 0 이상.
* 분모로 나눴으니 합은 1.
* 큰 점수는 더 크게, 작은 점수는 거의 0으로 — 지수함수의 성질 때문이다.

$\tau$(온도, temperature)는 지수함수의 "가파름"을 조절한다. $\tau$가 작을수록 $s_k/\tau$ 차이가 벌어져서 1등 항목이 거의 1, 나머지는 거의 0인 뾰족한 분포가 된다. $\tau$가 크면 차이가 눌려 균등분포에 가까워진다. (미적분에서 $e^{x/\tau}$의 기울기가 $1/\tau$에 비례한다는 것과 같은 이야기.)

DINO에서는 student에 $\tau_s = 0.1$, teacher에 더 작은 $\tau_t \approx 0.04\sim0.07$을 쓴다. teacher 쪽이 더 뾰족하다 — 이것을 **sharpening**이라 부른다.

## 3. 두 확률분포가 "얼마나 다른가": 크로스 엔트로피

두 분포 $p_t$(목표)와 $p_s$(예측)가 있을 때

$$H(p_t, p_s) = -\sum_{k=1}^{K} p_t^{(k)} \log p_s^{(k)}$$

를 **크로스 엔트로피**라고 한다. 직관: $-\log p_s^{(k)}$는 "$k$가 답이라고 밝혀졌을 때의 놀람"이다($p_s^{(k)}$가 작으면 크게 놀란다, $\log$의 그래프를 떠올리자). 그 놀람을 목표분포 $p_t$의 확률로 가중평균한 것, 즉 **놀람의 기대값**이다.

### 왜 $p_s = p_t$일 때 최소인가 (고교 수준 증명)

$\log x \le x - 1$ (등호는 $x=1$)은 $y=\log x$의 그래프가 $x=1$에서의 접선 $y = x-1$ 아래에 있다는 뜻이다(미적분: $\log x$는 위로 볼록). 이걸 이용하면

$$H(p_t, p_s) - H(p_t, p_t) = \sum_k p_t^{(k)} \log\frac{p_t^{(k)}}{p_s^{(k)}} = -\sum_k p_t^{(k)} \log\frac{p_s^{(k)}}{p_t^{(k)}} \ge -\sum_k p_t^{(k)}\left(\frac{p_s^{(k)}}{p_t^{(k)}} - 1\right) = -\sum_k p_s^{(k)} + \sum_k p_t^{(k)} = 0.$$

즉 크로스 엔트로피는 $p_s = p_t$일 때 가장 작다. 이 차이를 KL 발산 $\mathrm{KL}(p_t\|p_s)$라 부른다. 그러므로 "크로스 엔트로피를 줄여라" = "student의 분포를 teacher의 분포에 맞춰라"이다.

## 4. student와 teacher

같은 사진의 crop 두 장을 준비한다. 한 장은 **teacher** 신경망에, 다른 한 장은 **student** 신경망에 넣는다.

* student: 점수 $s$ → $p_s = \text{softmax}(s/\tau_s)$
* teacher: 점수 $t$ → $p_t = \text{softmax}((t - c)/\tau_t)$ (여기서 $c$는 다음 절의 "센터")

손실은 $\mathcal{L} = -\sum_k p_t^{(k)} \log p_s^{(k)}$. teacher의 출력 $p_t$는 **상수**로 취급하고(기울기를 흘려보내지 않음), student의 파라미터만 손실이 줄어드는 방향(음의 기울기 방향)으로 조금씩 움직인다.

teacher는 따로 학습하지 않는다. 대신 student 파라미터 $\theta_s$의 **지수이동평균**으로 만든다.

$$\theta_t \leftarrow \lambda\,\theta_t + (1-\lambda)\,\theta_s, \qquad \lambda \approx 0.994$$

이건 고교 수열의 점화식과 같다. $a_{n+1} = \lambda a_n + (1-\lambda) b_n$을 풀어 쓰면 $a_n$은 과거의 $b$들을 $\lambda^0, \lambda^1, \lambda^2, \dots$의 비율로 가중평균한 것이다. 즉 teacher는 "student의 최근 과거 여러 버전의 평균" — 개별 순간보다 안정적이고 조금 더 좋은 모델이 된다.

## 5. 센터링: 평균을 빼는 이유

라벨 없이 "둘을 같게 하라"고만 하면 **꼼수 해**가 있다. 신경망이 어떤 사진이든 1번 prototype 점수만 크게 내놓으면 student도 teacher도 항상 $p = (1, 0, 0, \dots)$가 되어 손실이 0이다. 배운 것은 아무것도 없다. 이런 현상을 **collapse(붕괴)**라 한다.

이를 막는 것이 **센터링**이다. 배치(한 번에 처리하는 사진 묶음) 안의 teacher 점수들의 평균을 $c$라 하고, 각 점수에서 $c$를 뺀다.

$$c \leftarrow m\,c + (1-m)\cdot\frac{1}{B}\sum_{i=1}^{B} t_i, \qquad m = 0.9$$

(여기도 이동평균 점화식이다.) 모든 사진이 공통으로 갖는 편향—"1번이 항상 크다"—은 평균 $c$에 들어가므로 빼면 사라진다. 남는 것은 **사진마다 다른 부분**뿐이다. 통계에서 자료에서 평균을 빼 편차만 보는 것과 같은 조작이다.

그런데 센터링만 하면 반대의 꼼수가 생긴다: 모든 사진에 대해 균등분포 $p = (1/K, \dots, 1/K)$를 내놓아도 손실이 같아진다. 이것을 막는 게 2절의 **sharpening**(작은 $\tau_t$)이다. teacher의 목표가 뾰족하므로 균등분포로는 손실이 줄지 않는다.

| 꼼수 | 막는 장치 |
|---|---|
| 한 prototype만 항상 켜기 | 센터링(평균 빼기) |
| 균등분포로 뭉개기 | sharpening(낮은 온도) |

두 힘이 균형을 이룰 때만 "사진마다 다르지만, 같은 사진의 crop끼리는 같은" 분포가 학습된다.

DINOv2는 EMA 센터링 대신 **Sinkhorn-Knopp**이라는 절차도 쓴다. $B$장의 사진 × $K$개 prototype 표를 만들어 "각 행(prototype)의 합도 같고, 각 열(사진)의 합도 1"이 되도록 행·열 정규화를 3번 번갈아 한다. 결과적으로 배치 안에서 prototype들이 사진을 **똑같이 나눠 갖게** 강제하는, 더 강한 형태의 센터링이다.

## 6. 전체 흐름 한 번에

1. 사진 한 장에서 큰 crop 2장(teacher, student 둘 다 봄)과 작은 crop 8장(student만 봄)을 만든다.
2. 각 crop → ViT → class token(벡터).
3. class token → DINO head → 길이 $K$ 점수 벡터.
4. student: $p_s = \text{softmax}(s/0.1)$. teacher: $p_t = \text{softmax}((t-c)/\tau_t)$, $\tau_t\approx0.04\sim0.07$.
5. 서로 다른 crop 쌍마다 $-\sum_k p_t^{(k)}\log p_s^{(k)}$를 계산해 평균 → $\mathcal{L}_{DINO}$.
6. student만 기울기로 갱신, teacher는 student의 이동평균, 센터 $c$도 이동평균으로 갱신.

수식은 결국 셋뿐이다: **softmax**(점수→확률), **크로스 엔트로피**(두 확률의 거리), **지수이동평균**(teacher와 센터). 셋 모두 고교의 지수함수·로그함수·수열 점화식으로 읽을 수 있다.
