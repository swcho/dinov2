# KoLeo regularizer — 고등학생을 위한 설명

**질문**: KoLeo regularizer의 정의와 목적은?

**답**: 배치 안의 각 벡터가 "가장 가까운 다른 벡터"와 떨어진 거리에 로그를 취해 평균한 뒤 음의 부호를 붙인 값
$$\mathcal{L}_{koleo} = -\frac{1}{n}\sum_{i=1}^{n}\log(d_{n,i}),\qquad d_{n,i}=\min_{j\ne i}\|x_i-x_j\|$$
이다. 이 값을 작게 만들면 벡터들이 서로 뭉치지 않고 고르게 퍼진다. 이름은 이 식이 **Kozachenko-Leonenko 엔트로피 추정**에서 나왔기 때문이다.

아래에서 이 식을 고교 수학(벡터, 로그, 미분, 확률)에서 출발해 한 단계씩 쌓아 올린다.

---

## 1단계. "특징 벡터"와 "거리"

신경망은 이미지 한 장을 숫자 여러 개로 된 **벡터** $x=(x^{(1)},x^{(2)},\dots,x^{(D)})$로 바꾼다. 고교에서 배운 2차원·3차원 벡터를 $D$차원으로 늘린 것뿐이다. 두 벡터 사이 **거리**도 피타고라스 정리 그대로다.

$$\|x_i-x_j\| = \sqrt{(x_i^{(1)}-x_j^{(1)})^2+\cdots+(x_i^{(D)}-x_j^{(D)})^2}$$

DINOv2는 이 벡터를 먼저 길이 1로 맞춘다($\ell_2$ 정규화: $x \leftarrow x/\|x\|$). 그러면 모든 벡터가 반지름 1인 구(2차원이라면 단위원) 위의 점이 되고, 비슷한 이미지는 구 위에서 가까운 점, 다른 이미지는 먼 점이 된다.

## 2단계. 최근접 이웃 거리 $d_{n,i}$

한 번에 $n$장의 이미지(배치)를 처리하면 점 $x_1,\dots,x_n$이 생긴다. 각 점 $x_i$에서 **자기 자신을 뺀 나머지 중 가장 가까운 점**까지의 거리를 $d_{n,i}$라 한다.

$$d_{n,i}=\min_{j\ne i}\|x_i-x_j\|$$

예를 들어 단위원 위에 세 점이 각도 $0^\circ, 10^\circ, 180^\circ$에 있다면(반지름 1인 원 위 두 점 사이 거리는 현의 길이 $2\sin(\theta/2)$):

| 점 | 다른 점까지 거리 | $d_{n,i}$ |
|---|---|---|
| $0^\circ$ | $10^\circ$까지 $0.174$, $180^\circ$까지 $2$ | $0.174$ |
| $10^\circ$ | $0^\circ$까지 $0.174$, $180^\circ$까지 $1.992$ | $0.174$ |
| $180^\circ$ | $0^\circ$까지 $2$, $10^\circ$까지 $1.992$ | $1.992$ |

## 3단계. 왜 $-\log$인가

로그 함수 $y=\log d$는 $d$가 0에 가까워질수록 $-\infty$로 곤두박질친다. 부호를 뒤집은 $-\log d$는 **$d$가 작을수록(뭉칠수록) 아주 커지고**, $d$가 크면 완만하게 작아진다.

위 예시에서 $\mathcal{L}_{koleo} = -\frac{1}{3}\bigl(\log 0.174+\log 0.174+\log 1.992\bigr) = -\frac{1}{3}(-1.749-1.749+0.689)\approx 0.936$.

만약 세 점을 $0^\circ,120^\circ,240^\circ$로 고르게 놓으면 모든 $d=2\sin 60^\circ=\sqrt3\approx1.732$이고 $\mathcal{L}_{koleo}=-\log 1.732\approx -0.549$로 훨씬 작다. 즉 **손실을 줄이는 것 = 뭉친 점을 떼어 놓는 것**이다.

왜 그냥 $-d$가 아니라 $-\log d$를 쓸까? 미분해 보면 이유가 보인다(4단계).

## 4단계. 미분해 보기 — 반발력

고교 미적분으로 $-\log d$를 $d$에 대해 미분하면 $-\dfrac{1}{d}$다. 거리가 $0.01$이면 기울기 크기가 $100$, 거리가 $1$이면 $1$. 즉 **가까울수록 훨씬 세게 밀어낸다**. 벡터에 대해 쓰면

$$\frac{\partial}{\partial x_i}\bigl(-\log\|x_i-x_j\|\bigr) = -\frac{x_i-x_j}{\|x_i-x_j\|^2}$$

방향은 $x_j$에서 $x_i$로 향하는 쪽(=서로 멀어지는 쪽), 크기는 거리에 반비례. 물리에서 배운 **같은 부호 전하의 반발**과 닮았다. 경사하강법은 이 기울기의 반대 방향으로 점을 옮기므로, 뭉친 점들은 서로를 밀어내며 퍼지고, 이미 멀리 떨어진 점은 최솟값에 관여하지 않아 그대로 둔다.

## 5단계. 엔트로피와 "고르게 퍼짐"의 관계 (이름의 유래)

확률과 통계에서 분포가 얼마나 "퍼져 있는지/불확실한지"를 재는 양이 **엔트로피**다. 이산 분포에서는 $H=-\sum p_k\log p_k$이고, 주사위처럼 모든 결과가 같은 확률일 때 최대가 된다. 연속 분포(확률밀도함수 $p(x)$)에서는 적분으로 바뀐다:

$$H(p)=-\int p(x)\log p(x)\,dx$$

정해진 영역(예: 구 표면) 안에서 엔트로피가 최대인 분포는 **균등분포**다. 그러니까 "특징을 고르게 퍼뜨린다"는 말은 "특징 분포의 엔트로피를 최대로 한다"와 같은 뜻이다.

문제는 우리에게 $p(x)$가 없고 표본 $x_1,\dots,x_n$만 있다는 점이다. 1987년 Kozachenko와 Leonenko는 **최근접 이웃 거리만으로** 엔트로피를 추정하는 식을 만들었다. 직관은 이렇다.

- 어떤 점 주변에 이웃이 바짝 붙어 있다 ⇒ 그 근처의 밀도 $p$가 높다 ⇒ $-\log p$가 작다 ⇒ 엔트로피에 조금 기여.
- 이웃이 멀다 ⇒ 밀도가 낮다 ⇒ 엔트로피에 많이 기여.

정량적으로는 점 $x_i$ 주변 반지름 $d_{n,i}$인 구 안에 이웃이 딱 하나 있으니 $p(x_i)\cdot V_D\,d_{n,i}^{\,D}\approx \frac{1}{n}$ 정도로 놓을 수 있고($V_D$: $D$차원 단위구 부피), 양변에 로그를 취해 정리하면 $-\log p(x_i)\approx D\log d_{n,i}+\text{상수}$가 된다. 이를 $n$개 점에 평균하면

$$\hat H_{KL} = \frac{D}{n}\sum_{i=1}^n \log d_{n,i} + \text{상수}$$

가 엔트로피의 추정값이다(상수는 $n$, $D$에만 의존하고 세부 보정항이 들어간다). 이제 비교해 보면

$$\mathcal{L}_{koleo} = -\frac{1}{n}\sum_i\log d_{n,i} = -\frac{1}{D}\hat H_{KL} + \text{상수}$$

즉 **KoLeo를 최소화하는 것 = 추정 엔트로피를 최대화하는 것 = 배치의 특징을 구 위에 균등하게 퍼뜨리는 것**이다. 이름 "KoLeo"는 **Ko**zachenko-**Leo**nenko의 앞 글자다.

## 6단계. DINOv2는 왜 이걸 넣었나

DINOv2는 "같은 이미지를 다르게 잘라(crop) 넣어도 비슷한 벡터가 나오도록" 학습한다. 그런데 이 목표만 좇으면 **서로 다른 이미지들까지 좁은 영역에 몰리는** 부작용이 생길 수 있다. 벡터가 몰리면 "이 이미지와 가장 비슷한 이미지를 찾아라" 같은 **이웃 찾기 과제**(k-NN 분류, 이미지 검색)가 어려워진다 — 다 붙어 있어서 누가 진짜 이웃인지 구분이 안 되니까.

KoLeo는 배치마다 최근접 이웃을 밀어내어 이 몰림을 막는다. 논문 실험 결과:

- ImageNet k-NN 정확도 76.6 → **78.9** (구성 요소 중 최대 향상)
- 이미지 검색(Oxford-M) mAP 55.6 → **63.9**, 반면 분류·분할 성능은 손해 없음

설정은 손실 가중치 0.1, 첫 번째 global crop의 class token에만 적용, GPU 안의 배치끼리만 계산이다. 같은 이미지에서 나온 두 crop 사이에는 걸지 않는다(그 둘은 가까워야 하니까 밀어내면 안 된다).

## 한눈에 정리

| | |
|---|---|
| 재료 | 배치의 벡터 $n$개 (길이 1로 정규화) |
| 각 점마다 | 가장 가까운 다른 점까지의 거리 $d_{n,i}$ |
| 손실 | $-\frac1n\sum\log d_{n,i}$ — 뭉치면 크고, 퍼지면 작다 |
| 미분 | 가까운 이웃에서 멀어지는 방향, 힘 $\propto 1/d$ (반발력) |
| 의미 | 최근접 거리로 추정한 엔트로피의 $-\frac1D$배 → 최소화 = 엔트로피 최대화 = 균등하게 퍼짐 |
| 효과 | 특징 몰림 방지, 이웃 찾기(검색·k-NN) 성능 향상 |
