# DINOv2 ablation에서 k-NN 성능을 최적화 기준으로 삼은 이유

> **Q.** DINOv2 ablation에서 k-NN 성능을 최적화 기준으로 삼은 이유는?
>
> **A.** 경험상 linear probe 성능이 k-NN 성능에 의해 **하한(lower bound)** 이 정해지기 때문이다. 즉 k-NN이 좋아지면 linear도 대체로 따라온다.

출처: Oquab et al., *DINOv2: Learning Robust Visual Features without Supervision* (arXiv 2304.07193), Sec. 6.1 및 Table 1 캡션.

원문 문장은 다음과 같다.

> "We optimize for k-NN performance, as in our experience, the linear probe performance is lower-bounded by the k-NN performance."

---

## 1. 두 평가가 각각 무엇을 측정하는가

두 평가는 모두 **백본을 얼린(frozen) 채로** ImageNet-1k 검증셋 Top-1 정확도를 재지만, 특징 공간을 "읽어내는 방식"이 다르다.

| | k-NN 평가 | Linear probe 평가 |
|---|---|---|
| 학습되는 파라미터 | **없음** (비모수적) | 선형층 `W, b` 하나 |
| 예측 방식 | 테스트 이미지의 특징과 학습셋 특징들의 코사인 유사도를 재고, 가장 가까운 k개의 레이블을 (가중) 투표 | `softmax(W·f(x)+b)`로 클래스 로짓 계산 |
| 추가 튜닝 여지 | k 정도만 | 학습률, 사용하는 출력 레이어 수, 패치 토큰 평균 concat 여부 등 (DINOv2 부록 B.3은 학습률 13개 × 레이어 {1,4} × concat {yes,no} 그리드 탐색 후 최고값 보고) |
| 무엇이 좋아야 점수가 오르나 | 같은 클래스의 샘플이 특징 공간에서 **실제로 서로 가까이 모여 있어야** 함 | 클래스들이 **어떤 초평면으로든** 갈릴 수 있으면 됨 (뭉쳐 있지 않아도 가능) |

### k-NN이 특징 공간의 "raw" 품질을 더 직접 반영하는 이유

- k-NN은 특징 벡터의 **기하(거리 구조)** 를 있는 그대로 사용한다. 같은 클래스가 뭉치고 다른 클래스가 떨어져 있지 않으면 어떤 트릭으로도 점수를 올릴 수 없다.
- Linear probe는 학습 가능한 선형 변환이 하나 끼어 있어, 특징 공간이 거리상으로는 지저분해도 "선형 분리 가능"만 하면 높은 점수가 나온다. 즉 **선형층이 특징의 결함을 어느 정도 보정**해 줄 수 있고, 하이퍼파라미터 탐색 폭도 커서 결과가 부풀려지거나 노이즈가 섞이기 쉽다.
- 따라서 "표현 자체가 좋아졌는가"를 판단하는 데는 k-NN이 더 순수한 신호이고, 학습 비용도 없어(선형층 학습 불필요) 여러 개의 ablation 모델을 빠르게 비교하기에 적합하다.

## 2. 왜 "linear는 k-NN에 의해 하한이 정해진다"고 말할 수 있는가

직관은 다음과 같다.

1. k-NN이 잘 된다는 것은 클래스별로 특징이 **조밀한 군집**을 이룬다는 뜻이다.
2. 서로 떨어진 조밀한 군집들은 대체로 **선형 분리도 가능**하다(군집 사이에 초평면을 그으면 된다). 그러므로 k-NN 정확도가 X%라면 선형 분류기도 최소 그 정도는 낼 수 있다.
3. 반대는 성립하지 않는다. 선형 분리는 가능하지만(linear 높음) 같은 클래스가 여러 군집으로 흩어져 있거나 클래스 간 거리가 애매한(k-NN 낮음) 특징 공간도 얼마든지 있다.

그래서 **k-NN ≤ linear** 라는 부등식은 거의 항상 성립하고, k-NN을 끌어올리면 linear의 바닥도 함께 올라간다. 반대로 linear만 보고 최적화하면 k-NN(즉 거리 구조)이 나빠지는 방향으로 빠져도 눈치채지 못할 수 있다.

### Table 4에서의 확인 (ImageNet-1k, frozen features)

같은 논문 Table 4는 여러 모델의 kNN과 linear 값을 나란히 보여 주는데, **모든 행에서 linear ≥ kNN** 이다.

| Method | Arch. | kNN | linear |
|---|---|---|---|
| MAE | ViT-H/14 | **49.4** | 76.6 |
| DINO | ViT-S/8 | 78.6 | 79.2 |
| iBOT | ViT-L/16 (IN-22k) | 72.9 | 82.3 |
| OpenCLIP | ViT-G/14 | 83.2 | 86.2 |
| DINOv2 | ViT-L/14 | 83.5 | 86.3 |
| DINOv2 | ViT-g/14 | 83.5 | 86.5 |

- MAE가 극단적인 예다. 선형 분류기를 붙이면 76.6이지만 k-NN은 49.4에 그친다. 픽셀 복원 목표로 학습된 MAE 특징은 "선형으로 읽어낼 수 있는 정보"는 담고 있지만 **거리 구조가 클래스와 정렬돼 있지 않다**는 뜻이다. 즉 k-NN은 linear가 감춰 주는 표현의 약점을 그대로 드러낸다.
- 하한이지 등호가 아니라는 점도 여기서 보인다: 격차는 모델마다 0.6(DINO)에서 27(MAE)까지 다르다.

## 3. Table 1: k-NN이 오르면 linear가 어떻게 따라오나

Table 1은 iBOT 기준선에서 시작해 DINOv2의 구성요소를 하나씩 누적 추가하며 ViT-L을 ImageNet-22k로 학습한 결과다(ImageNet-1k Top-1).

| 단계 | k-NN | Δ | linear | Δ |
|---|---|---|---|---|
| iBOT | 72.9 | | 82.3 | |
| + our reproduction | 74.5 | +1.6 | 83.2 | +0.9 |
| + LayerScale, Stochastic Depth | 75.4 | +0.9 | 82.0 | **-1.2** |
| + 128k prototypes | 76.6 | +1.2 | 81.9 | -0.1 |
| + KoLeo | 78.9 | +2.3 | 82.5 | +0.6 |
| + SwiGLU FFN | 78.7 | -0.2 | 83.1 | +0.6 |
| + Patch size 14 | 78.9 | +0.2 | 83.5 | +0.4 |
| + Teacher momentum 0.994 | 79.4 | +0.5 | 83.6 | +0.1 |
| + Tweak warmup schedules | 80.5 | +1.1 | 83.8 | +0.2 |
| + Batch size 3k | 81.7 | +1.2 | 84.7 | +0.9 |
| + Sinkhorn-Knopp | 81.7 | = | 84.7 | = |
| + Untying heads = DINOv2 | 82.0 | +0.3 | 84.5 | -0.2 |
| **누적** | **+9.1** | | **+2.2** | |

읽는 법:

- **큰 그림**: k-NN이 72.9 → 82.0으로 9.1점 오르는 동안 linear도 82.3 → 84.5로 함께 올랐다. k-NN을 기준으로 밀었지만 linear가 뒤따라온 것이다. 특히 KoLeo(+2.3), warmup 조정(+1.1), batch 3k(+1.2)처럼 k-NN이 크게 뛴 단계는 linear도 대부분 함께 올랐다.
- **격차가 좁아진다**: 시작 시점 linear − kNN 격차는 9.4점(82.3 − 72.9)이었지만 최종 DINOv2는 2.5점(84.5 − 82.0)이다. 각 구성요소가 "선형층이 보정해 주던 결함"을 표현 자체에서 없애 나갔다는 뜻이다.
- **중간에 linear가 내려가도 개의치 않았다**: LayerScale + Stochastic Depth(0.4) 단계는 linear를 1.2점 떨어뜨렸지만 k-NN은 올랐고, 무엇보다 학습 중 NaN loss를 막아 안정성을 높여 뒤따르는 개선들을 쌓을 수 있게 했다. k-NN이 오르고 있다면 linear의 바닥은 올라가고 있으므로, 일시적인 linear 하락은 나중에 회복될 것이라는 판단이다. 실제로 그 뒤 KoLeo 등에서 linear가 회복됐다.
- 논문은 이를 "각 구성요소가 k-NN 또는 linear 중 하나, 대부분은 둘 다를 개선하며, LayerScale과 Stochastic Depth만 linear가 소폭 떨어지지만 학습 안정성을 크게 높인다"고 요약한다.

## 4. 한 줄 정리

- **k-NN** = 학습 없이 거리 구조만으로 재는 특징 공간의 raw 품질.
- **linear probe** = 선형층 하나가 보정해 준 뒤의 성능이므로 항상 k-NN 이상(**하한**).
- 따라서 k-NN을 올리면 linear도 따라오지만 그 역은 보장되지 않는다. DINOv2는 이 경험적 규칙에 근거해 ablation의 1차 최적화 지표로 k-NN을 택했고, Table 1에서 k-NN +9.1과 함께 linear +2.2, 격차 9.4 → 2.5로 이를 확인했다.

## 관련 개념 (기억용 키워드)

- **frozen backbone 평가**: 백본을 미세조정하지 않고 특징만 뽑아 평가. DINOv2 논문 전체의 기본 프로토콜.
- **weighted k-NN**: DINO 계열이 쓰는 방식. 코사인 유사도를 온도로 나눈 뒤 지수화해 이웃 k개(보통 20)의 투표에 가중.
- **KoLeo regularizer**: 배치 내 특징들이 서로 밀어내도록 하는 항. Table 1에서 k-NN을 가장 크게(+2.3) 올린 구성요소로, 거리 구조를 직접 개선하는 항이라는 점과 일관된다.
