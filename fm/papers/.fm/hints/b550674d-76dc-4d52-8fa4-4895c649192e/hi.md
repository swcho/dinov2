# 부록 G는 왜 "분산"을 따로 보고했나 — 확률과 통계로 읽기

## 0. 먼저 상황 정리

이 논문(*Vision Transformers Need Registers*)의 Table 1은 이런 실험이다.

1. 이미지 한 장을 DINOv2-g에 넣는다.
2. 이미지가 쪼개진 여러 개의 patch token(작은 조각의 특징 벡터) 중에서 **딱 하나를 무작위로 고른다.** 단, 고르는 후보군을 "normal 토큰" 또는 "outlier(high-norm) 토큰"으로 제한한다.
3. 그 토큰 **하나**를 이미지 전체의 대표 표현으로 삼아, 그 위에 로지스틱 회귀(선형 분류기)를 학습시켜 이미지 분류 정확도를 잰다.

논문 본문의 표현 그대로다.

> "From those, we choose a single token at random, either high-norm or normal. This token is then considered as the image representation."

그리고 부록 G는 이렇게 말한다.

> "The results presented in table 1 are obtained by taking a random patch token, either normal or outlier. However, **the choice of this token adds a significant source of variance in the evaluation.** For thoroughness, we report in table 6 the standard deviation of the scores obtained relative to this choice."

즉 **"결과 숫자가 흔들리는 원인이 실험 프로토콜 안에 대놓고 들어 있으니, 그 흔들림의 크기를 같이 적어 둔다"** 는 것이다. 이게 카드의 답이다. 이제 이 문장을 고교 '확률과 통계' 언어로 풀어 보자.

---

## 1. 무엇이 확률변수인가 — "데이터"가 아니라 "선택"이다

고교 확률과 통계에서 **확률변수** $X$는 "시행의 결과에 실수를 대응시킨 함수"였다. 시행(trial)이 무엇인지부터 정확히 짚는 게 핵심이다.

여기서 시행은 **"어떤 patch token을 고를 것인가"** 라는 랜덤 추출이다. 데이터셋도, 모델 가중치도, 분류기 학습 방법도 전부 고정되어 있다. 오직 토큰 선택만 랜덤이다.

- 표본공간: $\Omega = \{\text{후보 토큰 } t_1, t_2, \dots, t_m\}$ (normal 조건이면 normal 토큰들, outlier 조건이면 outlier 토큰들)
- 확률변수: $X = (\text{그 토큰들을 뽑아 실험했을 때 얻는 분류 정확도})$

같은 코드를 시드만 바꿔 다시 돌리면 다른 토큰이 뽑히고, 그러면 정확도도 다른 값이 나온다. **정확도라는 "성능 숫자" 자체가 확률변수**인 것이다. 이 인식이 부록 G 전체의 출발점이다.

> 비유: 같은 반 학생 30명 중 한 명을 뽑아 그 학생의 키로 "이 반의 키"를 대표시킨다고 하자. 뽑는 학생이 바뀌면 "이 반의 키"가 통째로 바뀐다. 반 평균이 바뀐 게 아니라, **대표를 뽑는 방식이 랜덤이라서** 보고되는 숫자가 흔들린다.

## 2. 기댓값과 표준편차 복습 — 논문의 숫자는 무엇의 추정치인가

이산확률변수 $X$가 값 $x_1,\dots,x_m$을 각각 확률 $p_1,\dots,p_m$으로 가질 때,

$$E[X] = \sum_{i=1}^{m} x_i p_i = \mu$$

$$V[X] = E[(X-\mu)^2] = \sum_{i=1}^{m}(x_i-\mu)^2 p_i = \sigma^2, \qquad \sigma = \sqrt{V[X]}$$

$V[X] = E[X^2] - (E[X])^2$ 라는 계산용 공식도 그대로 쓰인다.

논문이 Table 1에 적은 정확도 숫자는 사실 $\mu = E[X]$ 그 자체가 아니다. 모든 토큰 조합을 다 시도해 볼 수는 없으니, **실험을 몇 번 반복해서 얻은 표본평균** $\bar{X}$ 다.

$$\bar{X} = \frac{1}{n}\sum_{k=1}^{n} X_k \quad (\text{추정치}) \;\longrightarrow\; \mu = E[X] \quad (\text{알고 싶은 참값})$$

그리고 Table 6에 $\pm$ 뒤에 붙은 숫자가 바로 $\sigma$의 추정치, 즉 **"이 실험을 한 번 돌리면 결과가 대략 이 정도 폭으로 흔들린다"** 는 정보다.

**여기서 오해하기 쉬운 점**: 표준편차는 "우리가 실수했다"는 뜻이 아니다. 프로토콜에 랜덤 추출이 들어 있으니 흔들림은 **필연**이다. 잘못은 흔들림이 있는 것이 아니라, 흔들림의 크기를 **말하지 않는 것**이다.

## 3. 왜 평균만으로는 부족한가 — 차이와 흔들림을 견주어 봐야 한다

논문이 Table 1로 주장하려는 것은 이것이다.

> "outlier 토큰은 normal 토큰보다 정확도가 훨씬 높다 → outlier 토큰이 이미지 전체의 global 정보를 저장하고 있다."

이 주장은 **두 조건의 평균 차이** 위에 서 있다.

$$D = \bar{X}_{\text{outlier}} - \bar{X}_{\text{normal}}$$

그런데 만약 각 조건의 표준편차 $\sigma$가 이 차이 $D$보다 크다면? 그러면 "다음번에 다시 돌리면 순서가 뒤집힐 수도 있다"는 뜻이고, 주장은 무너진다. **차이를 흔들림의 자로 재야 비로소 의미가 생긴다.** 대략적인 감각으로,

$$\text{신호 대 잡음} \approx \frac{|D|}{\sigma}$$

이 값이 크면 안전하고, 1 근처면 위태롭다.

### 논문의 실제 수치로 확인 (Table 1 + Table 6, Aircraft)

| 조건 | Table 1 (평균만) | Table 6 (평균 $\pm$ 표준편차) |
|---|---|---|
| normal | 17.1 | $17.1 \pm 0.5$ |
| outlier | 79.1 | $79.1 \pm 0.5$ |
| [CLS] | 87.3 | 87.3 (랜덤 선택 없음 → 표준편차 없음) |

계산해 보자.

$$D = 79.1 - 17.1 = 62.0, \qquad \sigma \approx 0.5$$

$$\frac{|D|}{\sigma} = \frac{62.0}{0.5} = 124$$

차이가 흔들림의 **약 124배**다. 시드를 바꿔 아무리 다시 돌려도 normal이 outlier를 이길 가능성은 사실상 없다. **결론은 안전하다.** 부록 G의 진짜 메시지는 "분산이 크니 결과를 믿지 마라"가 아니라, **"분산이 크다는 걸 알고 있고, 그럼에도 차이가 그보다 훨씬 크므로 결론은 살아남는다"** 는 방어인 것이다.

### [CLS] 행에 $\pm$ 가 없는 이유

Table 6에서 [CLS] 행만 표준편차가 붙어 있지 않다. [CLS] 토큰은 이미지마다 **딱 하나뿐이라 고를 필요가 없기** 때문이다. 랜덤 선택이라는 시행이 없으면 그로 인한 확률변수도 없고, 따라서 이 종류의 분산도 0이다. 이 대비가 "분산의 출처는 오직 토큰 선택"이라는 부록 G의 주장을 그대로 뒷받침한다.

### 흔들림이 큰 축에 속하는 예

Table 6 전체를 훑으면 $\pm$ 값이 데이터셋마다 다르다.

| 데이터셋 | normal | outlier |
|---|---|---|
| Airc. | $17.1 \pm 0.5$ | $79.1 \pm 0.5$ |
| CF10 | $97.1 \pm 0.1$ | $99.3 \pm 0.0$ |
| CF100 | $81.3 \pm 0.3$ | $93.7 \pm 0.3$ |
| CUB | $18.6 \pm 0.6$ | $84.9 \pm 2.1$ |
| Cars | $10.8 \pm 0.3$ | $85.2 \pm 0.9$ |
| DTD | $63.1 \pm 0.8$ | $84.9 \pm 0.9$ |
| Flow. | $59.5 \pm 1.2$ | $99.6 \pm 0.0$ |
| Food | $74.2 \pm 0.3$ | $93.5 \pm 0.2$ |
| IN1k | $65.8 \pm 0.1$ | $69.0 \pm 0.7$ |
| P205 | $53.1 \pm 0.3$ | $55.1 \pm 1.0$ |
| Pets | $47.8 \pm 0.5$ | $94.1 \pm 0.2$ |
| SUN | $37.7 \pm 0.3$ | $78.5 \pm 0.2$ |
| VOC | $70.8 \pm 0.5$ | $89.7 \pm 0.1$ |

(Cal101 열은 마크다운 변환본에서 Table 1의 outlier 값 97.6과 Table 6의 값이 어긋나 보여, 변환 오류 가능성이 있으므로 여기서는 제외했다. 확인되지 않은 값은 추측하지 않는다.)

여기서 두 가지를 읽을 수 있다.

- **가장 흔들리는 칸**: CUB outlier의 $\pm 2.1$. 다시 돌리면 82.8 ~ 87.0 정도까지 왔다 갔다 할 수 있다는 뜻이다. 그런데 normal은 18.6이므로 차이 $D = 66.3$, $|D|/\sigma \approx 32$. 여전히 압도적이다.
- **가장 아슬아슬한 칸**: IN1k와 P205. IN1k는 $D = 69.0 - 65.8 = 3.2$이고 outlier 쪽 $\sigma = 0.7$이라 $|D|/\sigma \approx 4.6$. P205는 $D = 55.1 - 53.1 = 2.0$, $\sigma = 1.0$이라 $|D|/\sigma \approx 2$. **평균만 적힌 Table 1만 봤다면 "IN1k도 outlier가 이겼다"고 똑같은 무게로 읽었을 텐데, 표준편차를 보면 이 두 데이터셋의 우세는 Aircraft만큼 견고하지 않다는 게 드러난다.** 부록 G가 있어야만 얻을 수 있는 정보가 정확히 이런 것이다.

## 4. 평균의 표준오차 — 흔들리는 실험에서 믿을 만한 숫자를 뽑는 법

"토큰 하나만 뽑는 실험은 이렇게 흔들리는데, 어떻게 $\pm 0.5$ 같은 작은 값이 나오지?" 하는 의문이 남는다. 답은 고교 통계의 **표본평균의 분포**에 있다.

모평균 $\mu$, 모표준편차 $\sigma$인 모집단에서 크기 $n$인 표본을 뽑아 표본평균 $\bar{X}$를 만들면,

$$E[\bar{X}] = \mu, \qquad \sigma(\bar{X}) = \frac{\sigma}{\sqrt{n}}$$

유도도 어렵지 않다. $X_1,\dots,X_n$이 서로 독립이고 각각 분산 $\sigma^2$일 때, 독립인 확률변수의 분산은 더해지므로

$$V\!\left[\sum_{k=1}^n X_k\right] = n\sigma^2 \;\Longrightarrow\; V[\bar{X}] = V\!\left[\frac{1}{n}\sum X_k\right] = \frac{1}{n^2}\cdot n\sigma^2 = \frac{\sigma^2}{n}$$

양변에 제곱근을 씌우면 $\sigma/\sqrt{n}$. 이 $\sigma/\sqrt{n}$ 을 **평균의 표준오차(standard error)** 라 부른다.

핵심은 이 한 줄이다.

$$\boxed{\;\text{한 번의 실험은 } \sigma \text{ 만큼 흔들려도, } n \text{ 번 평균 내면 흔들림은 } \sigma/\sqrt{n} \text{ 로 줄어든다.}\;}$$

수치 감각을 잡아 보자. 토큰 하나를 뽑는 개별 시행의 흔들림이 $\sigma = 10$ 이라 해도,

| $n$ | $\sigma/\sqrt{n}$ |
|---|---|
| 1 | 10 |
| 100 | 1.0 |
| 2,500 | 0.2 |
| 10,000 | 0.1 |

즉 수천 장의 테스트 이미지에 대해 각각 토큰을 뽑아 평균 내면, 개별 선택의 거친 흔들림은 $\sqrt{n}$ 에 반비례해 눌린다. Table 6의 $\pm 0.1 \sim \pm 2.1$ 이라는 비교적 작은 값들은 이미 이렇게 **평균으로 눌린 뒤** 남은 흔들림이다.

주의할 점: $\sqrt{n}$ 이 분모라는 건 **수익 체감**을 뜻한다. 흔들림을 $\frac{1}{10}$ 로 줄이려면 실험을 10배가 아니라 **100배** 해야 한다. 그래서 "그냥 많이 돌리면 되지"가 항상 답은 아니고, 애초에 분산이 작은 프로토콜을 설계하는 게 더 중요하다.

## 5. 실험 설계 교훈 — 이 카드가 진짜 가르치는 것

부록 G는 한 문단짜리 짧은 절이지만, 담긴 원칙은 논문 전체에 적용된다.

**프로토콜 안에 랜덤 선택이 들어 있으면, 그 무작위성이 만드는 분산을 반드시 함께 보고해야 한다.**

정리하면.

1. **랜덤이 어디에 있는지 지목하라.** 여기서는 데이터도 모델도 아니고 "토큰 하나를 고르는 행위"였다. 분산의 출처를 이름 붙여 말할 수 있어야 한다.
2. **평균만 적힌 표는 절반의 정보다.** 같은 평균 차이라도 $\sigma$가 얼마냐에 따라 "확정적 결론"일 수도, "우연일 수도 있는 차이"일 수도 있다.
3. **차이는 흔들림을 자로 삼아 재라.** $|D|/\sigma$ 가 크면 결론이 견고하다. Aircraft는 124배라 안전하고, P205는 2배라 조심스럽다.
4. **표본을 늘리면 평균의 흔들림은 $\sigma/\sqrt{n}$ 으로 줄지만, 개별 시행의 $\sigma$ 자체는 줄지 않는다.** 둘을 혼동하지 말 것.
5. **랜덤 선택이 없는 조건([CLS])은 그 분산도 없다.** 어떤 조건에 오차 막대가 붙고 어떤 조건에 안 붙는지를 보면, 그 실험의 무작위성이 어디서 오는지 역으로 읽어낼 수 있다.

## 한 줄 요약

Table 1은 normal / outlier 후보 중 patch token **하나를 무작위로** 골라 평가하므로, 그 **토큰 선택 자체가 큰 분산의 원천**이다. 그래서 부록 G는 Table 6에 같은 결과를 표준편차와 함께 다시 실어, 표에 적힌 평균 차이가 흔들림보다 충분히 커서 결론이 유효함을 보인 것이다.
